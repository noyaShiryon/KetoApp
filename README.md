אפליקציית מובייל חכמה למעקב תזונה קיטוגנית וצום לסירוגין המבוססת על בינה מלאכותית (Google Gemini AI). האפליקציה מאפשרת לתעד ארוחות באמצעות צילום מהיר מהמצלמה, לחתוך את התמונה באופן חופשי, לקבל ניתוח ערכים תזונתיים מדויק, ולערוך אותם ידנית לפני נעילה סופית ביומן.

## 🚀 פיצ'רים מרכזיים

* **📸 ניתוח ארוחות מבוסס AI:** צילום של הצלחת ופענוח מיידי של רכיבי המזון, המשקל המשוער והערכים התזונתיים (פחמימות נטו, חלבון, שומן וקלוריות).
* **⚠️ התרעת פחמימות חבויות:** ה-AI סורק את המנה ומזהה רכיבים חשודים כמו סוכר סמוי, עמילנים או רטבים שעלולים להוציא מקטוזיס.
* **✏️ עריכה ותיקון ידני (Manual Override):** אפשרות לתקן את משקלי המזון בגרמים מיד לאחר הצילום. המערכת מחשבת מחדש את הערכים באופן יחסי (Proportional Scaling).
* **🔒 מנגנון נעילת ארוחה:** לאחר אישור ערכי הארוחה, היא ננעלת ולא ניתנת לעריכה נוספת כדי לשמור על אמינות יומן התזונה.
* **⏳ חישוב חלון צום אוטומטי:** חישוב דינמי של שעות הצום היומיות על בסיס זמני הארוחות המתועדות.
* **📊 מדד קטוזיס יומי (Progress Bars):** דאשבורד מעוצב עם פסי התקדמות צבעוניים המציגים את מצב הפחמימות, החלבון והשומן ביחס ליעד האישי.
* **💬 הודעות עידוד חכמות:** בועת מוטיבציה המשתנה דינמית לפי מצב הקיטו והצום היומי שלך.
* **💾 שמירה מקומית והיסטוריה שבועית:** שמירת הנתונים על המכשיר באמצעות `AsyncStorage` ומסך ייעודי להצגת ההתקדמות והחריגות לאורך השבוע.
* **🛡️ אבטחת מפתחות (Security First):** הפרדה מלאה של ה-API Key באמצעות משתני סביבה (`.env`) כדי למנוע דליפת סודות ל-Git.
